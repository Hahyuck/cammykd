# 제작 기록 — code.js (해상 요새 투어)

실시간 three.js 월드를 HTML 한 장으로 만든 과정과 구성 요소를 정리한 문서입니다.
작성 기준일: 2026-11-14. 제작: DIVIDE01 (최하혁) + Claude.

## 1. 한 줄 요약

ChetasLua의 **Crimson Loong**(코드만으로 만든 three.js 단일 HTML 영상)의 하늘·빛·물 엔진 위에,
용과 계곡 대신 **벽돌 타워와 항구 마을을 코드로 새로 지어** 올린 실시간 월드입니다.
텍스처 파일 없이 모든 표면을 셰이더가 그리고, 하루(6분)가 맑음 → 폭풍 → 노을로 끝없이 순환합니다.

## 3. 파일 구성

```
index.html          빌드 결과물 (이 한 장이 전부)
src/                모듈 (번호순으로 이어 붙여 한 장이 됨)
tools/build.py      빌드: three.js + src/*.js → 단일 HTML
vendor/             three.js r180
scripts/            GLB 가공·카메라 궤도 생성 스크립트 (Python)
```

빌드: 원작 저장소 구조(`ws/<이름>/src`)에 `src/`를 두고 `python3 tools/build.py <이름>`.

## 4. 핵심 기법

**시간의 함수.** 모든 그림은 시간 t의 순수 함수입니다. 투어에서는 시계를 둘로 나눴습니다.
카메라 시계(90초 궤도 반복)와 환경 시계(하늘·빛·날씨, 0.25배속 → 하루 6분). 그래서 영상이 끝나지 않고 해가 천천히 움직입니다.

**GLB → 코드.** GLB를 용접·간소화한 뒤 위치 기준 연결 성분으로 18조각으로 나누고, 2 m 격자 높이 지도를 뽑아
"어디에 무엇이 얼마나 높게 서 있었나"만 읽었습니다. 건물 자체는 키트 함수(벽 상자, 박공·볼트 지붕, 창 격자, 탱크, 굴뚝, 부두, 격자 붐)의 호출로 새로 지었습니다.

**하나의 절차적 재질.** 정점마다 (u, v) 미터 좌표·재질 번호·변형 번호를 싣고, 셰이더 하나가 벽돌·도장 철판·맨 강철·지붕·유리·목재·콘크리트·골함석·경고 도색을 그립니다.
범프는 절차적 높이의 화면 공간 미분으로 만들고, 창과 가로등은 폭풍·황혼에 켜집니다. 텍스처가 없어서 가까이 가도 흐려지지 않습니다.

**포말을 세운 이유.** 수면 높이 3 m 카메라에서 수면 위 포말 1 m는 0.2픽셀이 안 됩니다. 그래서 흰색을 수직으로 세웠습니다:
벽면 수면선의 흰 띠(파도마다 오르내림)와 벽을 따라 튀는 물보라. 둘은 같은 위상 함수를 써서 박자가 맞습니다.

**낙뢰는 카메라 기준.** 고정 방위에 두면 건물에 가려 안 보였습니다. 치는 순간의 카메라 시야 기준(좌우 9–25°, 700–1000 m)으로 배치하고, 천둥은 거리/343 m/s만큼 늦게 울립니다.

**검증 방식.** 클라우드에는 GPU가 없어 렌더를 확인할 수 없었습니다. 페이지를 게시해 제작자 PC(RTX 4090)의 Chrome에서 열고,
주소 해시(`#t40` 카메라 시각, `#e28` 환경 시각, `#play`, `#hud`)로 장면을 고정해 스크린샷으로 확인했습니다.

## 5. 겪은 문제와 해결

| 문제 | 원인 | 해결 |
|---|---|---|
| 마을 앞에서 물이 끊김 | 수면 메시가 원작 호수 크기(118×132 m)로 고정 | 전체 영역으로 확장 |
| 섬을 올리자 옆 건물이 찌그러짐 | 매끄러운 높이 변형이 이웃을 끌어당김 | 조각별 강체 이동으로 교체 |
| 시계 분리 후 검은 화면 | 로더 뒤 프레임이 반복 횟수를 음수로 만듦 | 재생 시작 시 초기화 |
| 포말이 안 보임 | 낮은 시점에서 수평 포말은 서브픽셀 | 벽면 띠 + 물보라 |
| 부두 바닥이 반짝임 | 같은 평면에 면 두 장(부두 겹침, 본체 윗면과 상판) | 한 장만 남기고 부두 사이에 수로 |

## 6. 조작

투어는 자동 재생. `W A S D` + 마우스(클릭 또는 드래그)로 자유 이동, `Q`/`E` 하강/상승, `Shift` 가속, `R` 투어 복귀.
자유 이동 중 8초간 입력이 없으면 4.5초에 걸쳐 투어 궤도로 미끄러져 돌아갑니다(R·두 번 탭도 같은 방식).
로딩 화면은 대문입니다: 왼쪽에 최초 컨셉 이미지, 오른쪽에 구현 목록(이미지·엔진·작성한 JS·이펙트), 아래에 진행 막대.
클릭하면 소리, `M` 음소거, `Space` 일시정지. 모바일은 보이지 않는 터치 패드로 조작합니다: 화면 왼쪽 절반을 누른 채 밀면 이동, 오른쪽 절반을 밀면 시점 회전, 두 번 탭하면 투어 복귀.
