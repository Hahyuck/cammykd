# GBA PocketFrame — Store Listing Draft

## App name
GBA PocketFrame

## Short description
Offline GB, GBC & GBA emulator frontend. Free, open-source, no ads or tracking.

## Full description
GBA PocketFrame is a lightweight, offline emulator frontend for Game Boy, Game Boy Color, and Game Boy Advance game files that you provide yourself.

Built around the open-source mGBA emulator core, PocketFrame focuses on a simple handheld-style experience with touch controls, physical-controller support, quick save/load, speed controls, scanline options, and customizable control layouts.

Highlights:
- GB, GBC and GBA support
- Open ROMs from Android storage
- ZIP and 7z archive support
- Native in-game save persistence
- Quick Save / Quick Load
- 1x, 1.5x, 2x and 3x speed options
- Portrait and landscape play
- Customizable touch-control position, size and opacity
- Physical gamepad support
- Local diagnostic report for troubleshooting
- No ads
- No tracking or analytics
- No account or login
- No subscriptions or in-app purchases
- No Internet permission

Games, ROM files and proprietary BIOS files are not included. You are responsible for using game files that you are legally entitled to use.
