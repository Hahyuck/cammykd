GBA PocketFrame Privacy Policy

Effective date: October 7, 2026

GBA PocketFrame is a local emulator application for compatible Game Boy, Game Boy Color, and Game Boy Advance game files supplied by the user.

Data used on your device

ROM and archive files you select through Android's file picker are read on your device to provide emulation. Save RAM, save states, and on-screen control-layout preferences are stored locally. Touch, Bluetooth, and USB controller input is used to control games; individual button presses are not recorded or transmitted.

The app keeps a local technical diagnostic log to help investigate unexpected exits and save/load problems. It can contain timestamps, app activity, a short SHA-256 identifier for a selected ROM, file or save-state sizes, frame count, speed, scanline mode, screen orientation, save/load outcomes, error messages, and Android process-exit details. An exported report also includes the app version, Android SDK level, device model, and device ABI. Routine diagnostic events do not add ROM filenames or contents, but error or process-exit messages may contain filenames, paths, or other details.

Collection and sharing

GBA PocketFrame has no account system, advertising or analytics SDK, tracking, developer server, or Internet permission. The app does not automatically send ROMs, save data, controller input, diagnostics, or personal information to the developer or third parties, and the developer does not sell this data.

You can choose to export a diagnostic report to a location selected through Android's file picker. If you later share that file with another app or service, that destination handles it under its own privacy policy. Review the report before sharing it.

Data retention and deletion

App-private save data and diagnostics remain on your device until you clear the app's data or uninstall it. You can clear the diagnostic log separately in the app. Uninstalling removes app-private data; original ROMs and exported reports stored elsewhere may remain in their chosen locations. Android automatic backup is disabled for the app. The developer does not retain data on a server.

Third-party code

GBA PocketFrame uses the open-source mGBA emulation core and open-source archive libraries. These components are used locally for emulation and archive decoding and do not cause GBA PocketFrame to collect user data.

Games and ROM files

Games, ROM files, copyrighted game assets, and console firmware are not included with GBA PocketFrame. Users are responsible for using files they are legally entitled to use.
