GBA PocketFrame Privacy Policy

Last updated: October 7, 2026

GBA PocketFrame is a local, offline emulator frontend. It does not include games or ROM files.

Data collection

GBA PocketFrame does not collect, transmit, sell, or share personal information. The app contains no advertising SDK, analytics SDK, account system, or Internet permission.

Local files

ROM files selected by the user are accessed only on the device through Android's document picker. Save RAM, quick-save states, controller settings, and control-layout preferences are stored locally on the device.

Local diagnostics

The app may keep a small local diagnostic log to help identify unexpected exits. It can include the app version, Android version, device ABI, anonymous ROM hash identifier, emulator speed, screen orientation, and recent emulator actions such as save/load or pause/resume. Diagnostic information is not uploaded automatically. The user may export the report manually or clear it from the app.

Backups

Android automatic backup is disabled for the app.

Third-party software

GBA PocketFrame uses open-source components including the mGBA emulator core. Open-source license notices are available inside the app and with the published source materials.

Games and intellectual property

No commercial games, ROMs, BIOS files, Nintendo artwork, or other copyrighted game content are included. Users are responsible for using files they are legally entitled to use. GBA PocketFrame is an independent project and is not affiliated with or endorsed by Nintendo or other game publishers.

Contact

For privacy questions or bug reports, use the project's public GitHub issue tracker.
