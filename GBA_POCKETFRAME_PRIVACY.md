# GBA PocketFrame Privacy Policy

Effective date: October 7, 2026

GBA PocketFrame is a local emulator application for compatible Game Boy, Game Boy Color, and Game Boy Advance game files supplied by the user.

## Data collection and sharing

GBA PocketFrame does not collect, transmit, sell, or share personal data. The app does not include advertising SDKs, analytics SDKs, account systems, cloud services, or an INTERNET permission.

ROM and archive files selected by the user are read locally on the device solely to provide emulation functionality. Save RAM and save-state files are stored locally in the app's private storage. GBA PocketFrame does not upload ROMs, save data, controller input, or other user content.

Bluetooth and USB game-controller input is processed locally and is not recorded or transmitted.

## Data retention and deletion

Local save data remains on the device until the user removes it through app/device storage management or uninstalls the app. Because GBA PocketFrame does not operate a server or user account system, the developer does not retain user data off-device.

## Third-party code

GBA PocketFrame uses the open-source mGBA emulation core and open-source archive libraries. These components are used locally for emulation and archive decoding and do not cause GBA PocketFrame to collect user data.

## Games and ROM files

Games, ROM files, copyrighted game assets, and console firmware are not included with GBA PocketFrame. Users are responsible for using files they are legally entitled to use.
